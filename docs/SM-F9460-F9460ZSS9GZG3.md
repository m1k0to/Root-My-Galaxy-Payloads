## 关键结论(重要)

1. **内核构建族 `33404244`** —— 与 `rmg-f731u` 的 F731U
   (`5.15.189-android13-8-33404244-abF731USQS8GZF1`) **同一内核构建**。
   rmg-f731u 文档证明:q5q ↔ F731U 符号偏移仅差 **+0x40(64 字节)**。
   ⟹ 三星内核 Image 在该构建族内共享,符号偏移相同;固件后缀(usqs/zss)只是构建标签,
   不改变内核布局。
   ⟹ **F9460(q5q) exploit 偏移 = F731U payload 反向 -0x40**(见 `tools/` 反向补丁 spec)。

2. **KernelSU 模块 vermagic** 含完整固件后缀:
   `5.15.189-android13-8-33404244-abF731USQS8GZF1 SMP preempt mod_unload modversions aarch64`
   ⟹ F731U 的 `.ko` **不能**直接用于 F9460,须针对
   `5.15.189-android13-8-33404244-abF9460ZSS9GZG3` 重新编译 KernelSU 模块
   (需三星 q5q OSS 内核源码 + config)。

  确定为同构建族且无需重新适配时用,需真机验证。
